Usage Rules

✓ Do

Use the primary logo on white and light grey backgrounds.

✓ Do

Use the white logo on the brand teal, dark blue, and photographic backgrounds.

✓ Do

Maintain clear space equal to the height of the logomark on all sides.

✓ Do

Use SVG source files. Scale from vector, never enlarge raster assets.

✗ Don't

Stretch, skew, rotate, or add drop shadows to the logo.

✗ Don't

Change the brand colors, add outlines, or place the logo on busy photographic backgrounds without a container.

✗ Don't

Use the wordmark without the logomark in app headers, favicons, or social profile images.

✗ Don't

Use "Topflowng", "topflowNG", or other casing variants. The correct name is TopFlowNG.
