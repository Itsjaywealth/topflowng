# Provider logo sources

All assets are stored locally; the application does not hotlink provider logos.
The files are displayed without recolouring or geometric distortion.

| Glo | Official Globacom favicon: `gloworld.com/favicon.ico` |
| 9mobile | Secondary verified trademark copy from Logowik because `9mobile.com.ng` did not respond during acquisition |

presented as active customer products. EEDC is not in the verified electricity
catalogue and therefore does not appear as a selectable provider.
